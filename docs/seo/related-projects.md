# Related project discovery

Related lists stay within a project type and contain at most three published entries.
For the exact reviewed Bend 2 identities below, two slots prefer other reviewed
Bend 2 peers. One slot always retains the next slug in the complete category ring,
wrapping at the end, so classic and unclassified builds keep a browse path.
Unreviewed identities keep the original category ring unchanged. No title,
description or substring matching infers a language generation. This is relevance
ordering, not a quality ranking or a compiler-compatibility guarantee.
