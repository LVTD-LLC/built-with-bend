# Curator access

Browsing and submissions do not require an account. Public signup is closed.

Curators use the [admin sign-in](/admin/). Ask the site operator for access and credentials through a private channel. Never share API keys in a submission or public issue.

Curators can review pending submissions and publish or archive projects. Contact details and review notes remain private.
