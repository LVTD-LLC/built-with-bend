# Discover what people build with Bend 2

Built with Bend is an independent, human-reviewed directory. Browse the [collection](/), follow a live demo or repository, and explore the original sources.

## Share a build

1. Open [Submit a build](/submit/).
2. Add a public source link, a name, and a description of how the project uses Bend 2.
3. Include a live website or repository when available. Closed-source projects are welcome.
4. Send it for review. It appears publicly only after a curator approves it.

You do not need an account. Contact details are optional and stay private.
