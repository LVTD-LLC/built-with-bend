# Renderer fonts

Unmodified DejaVu Sans regular/bold and DejaVu Serif italic, bundled from
Matplotlib v3.10.1 (`lib/matplotlib/mpl-data/fonts/ttf/`).

Source: https://github.com/matplotlib/matplotlib/tree/v3.10.1/lib/matplotlib/mpl-data/fonts/ttf

Redistribution terms are in `LICENSE_DEJAVU`. Bundling keeps server-side image
rendering independent of operating-system fonts and external services.
