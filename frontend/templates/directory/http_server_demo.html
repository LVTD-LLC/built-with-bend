Try a smaller, local HTTP example

The official Bend 2.0.35 HTTP demo is a separate starting point, not a fix for the project above. Built with Bend compiled that unmodified demo and received one HTTP 200 response with a Hello, world! body on October 22, 2026.

From that version’s compiler repository, build with bend demos/io_http_server/main.bend -o http_server, run ./http_server --threads 1, then request http://127.0.0.1:8080/ from another terminal. Stop the process when finished. It binds only to the local machine and returns a fixed page; it does not provide the listed project’s routes or GPU workload.

This was one local smoke check, not a benchmark or production-readiness test. The demo’s check-only and proof commands, including --verdict, rejected unsafe or foreign-code dependencies on that compiler. A running HTTP response is not a passing proof.
