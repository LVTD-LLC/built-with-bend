Try Bendo’s local Bend 2 web server

Start with Bendo’s hello example to explore a Bend 2 web framework before adding a frontend. Bendo is pre-alpha: its maintainer has not published the toolkit to npm, and the API can change. Use the checkout instructions, not the prospective bun create bendo command.

The pinned quick start specifies Bend 2.0.38, Bun 1.4.4 and clang. Follow its versioned compiler download rather than assuming the latest Bend installer matches. After cloning, select the checked source with git checkout a42deb9.

  1. In the Bendo checkout, compile bend examples/hello/main.bend -o hello, then start ./hello.
  2. In a second terminal, run curl http://127.0.0.1:8787/todos/42. Expect Hello from Bendo! You asked for /todos/42. Stop the server when finished.

For a larger starting point, the checkout-only scaffolder offers an API template or a fullstack template with React and a typed client. Those templates are separate from the hello example tested here.

Built with Bend checked the unmodified hello source on November 2, 2026: it compiled with Bend 2.0.38 on Linux x64 and returned the expected local HTTP response. This was a smoke check, not a benchmark, proof-kernel check, template test or production recommendation.
