Try your first proof check in the browser

No compiler installation or AI-provider key is needed for this exercise. Open the v4 demo, choose Original, and press Run the checks. Repeat with Refactor slip, then Raise the limit to 1500. In our October 23 check, the results were pass, fail, and pass: a code change does not necessarily break the written law.

The demo uses Bend 2.0.25’s ordinary checker, not the independent --verdict kernel check. It does not run IO programs or fetch hub packages, and its parallel-work animations are not benchmarks. Leave the optional LLM panel closed; it is separate from this exercise.
