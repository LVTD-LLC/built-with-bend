Before trying the published Knot CLI

The npm release metadata for @matheusbbarni/knot 0.0.1 lists a Node.js launcher and platform-specific binaries. Installing the package and starting the CLI are separate checks.

On October 28, 2026, Built with Bend installed that exact version in an isolated directory with lifecycle scripts disabled. On our Linux x64 host with glibc 2.36 and Node.js 24.21.0, both knot --version and knot --help failed before Knot started: the native binary required GLIBC_2.38, which this host did not provide. The binary’s SHA-256 matched the published wrapper’s expected hash. This is one host result, not a claim that every Linux installation fails or that a newer glibc guarantees success.

For the maintainer’s installation options, use the pinned installation instructions. The separate source-build instructions name Node.js 24 LTS, Bend 2.0.24 and a native C compiler. We have not tested that build as a workaround, other platforms, or package operations. Transpilation is not type-checking; the test runner remains planned.

Release and sources checked October 28, 2026. These checks do not certify compatibility, security or production readiness.
