Start editing Bend 2 in Neovim

Bend2.nvim provides native Lua editing support without Node.js or a separate language-server executable. Editing works without the Bend compiler; compiler-backed checks, proof workflows, Bend Base completion, builds and runs require an installed Bend 2.0.28 or newer, according to the maintainer.

For Neovim 0.11 or newer, choose the maintainer’s lazy.nvim instructions or native package layout. The plugin is installed from Git, with a published v1.0.0 release. The separate vim.pack option requires Neovim 0.12 or newer and uses an experimental API.

Once the plugin and compiler are configured, open examples/proof-workflow/main.bend from the plugin repository, then try :Bend2CheckWorkspace and :Bend2Proofs. The pinned proof-workflow example and source show the starting project; the configuration reference explains compiler selection and help commands. A successful check is not a guarantee about unwritten requirements or production readiness.

Sources reviewed October 27, 2026. Built with Bend has not installed or run this plugin. The maintainer’s documented compiler test matrix covers 2.0.28 and 2.0.32, not every later version; a supported-version claim is not a compatibility test.
