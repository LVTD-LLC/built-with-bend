Try the ezmcp stdio demo

Want to see a Bend 2 tool server answer before connecting an agent client? Start with the upstream demo’s newline-delimited JSON-RPC interface. This checks the local server directly; it is not a client configuration or an end-to-end agent test.

On November 5, 2026, Built with Bend built the unmodified demo at 222124b on Linux x64 using Bend 2.0.38 and Clang 14.0.6. Use that compiler version and the native C build below, not the JavaScript lane. Hash-pinned imports need access to the Bend hub or an existing dependency cache.

With Git, Bend 2.0.38 and Clang installed, use a fresh working directory. These commands follow the pinned build instructions and the demo’s tool definitions. The JSON input is our local smoke check:

git clone https://github.com/Emerging-Patterns/ezmcp.git
cd ezmcp
git checkout 222124b0814a3e5c1193e78eba0392e709b99174
cd examples/demo
bend main.bend -o demo
./demo stdio <<'JSONL'
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"local-smoke","version":"1"}}}
{"jsonrpc":"2.0","method":"notifications/initialized"}
{"jsonrpc":"2.0","id":2,"method":"tools/list"}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"add","arguments":{"a":2,"b":40}}}
JSONL

The checked run answered initialization with protocol version 2025-11-25, listed echo and add, and returned structuredContent containing {"sum":42} for request 3. The initialized notification has no response. In separate negative checks, passing "two" instead of integer 2 to add returned a tool result with isError: true; asking for an unknown tool returned JSON-RPC error -32602. Those are different failure paths, not successful calls.

For HTTP use, read the pinned transport limits first: ezmcp supplies no authorization, so keep a local demo on 127.0.0.1; remote access needs an authenticating proxy. The implementation scope lists unsupported features, including resources, prompts and sessions. This November check covers stdio only, not HTTP, an agent client, other platforms, the full conformance suite, proof verification or security certification. The earlier October check above remains a separate dated result.
