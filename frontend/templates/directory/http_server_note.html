Before you run this HTTP server

Built with Bend checked source revision 66a9258 with Bend 2.0.35 on October 15, 2026. It needs compatibility work before it can run with that compiler.

bend main.bend --check-only stops at TCP.listen(port()) in the server entry point: the checker expects a string but receives a U32. The Bend 2.0.35 guide specifies TCP.listen(host, port). This is the first failure, not a verified one-line fix.

The separate bend PROOF.bend --verdict check passes. Those laws cover the computation and its bound, not socket behavior, HTTP correctness, or a successful server build. We did not run or benchmark the server, test GPU execution, or establish compatibility with other compiler versions.

For source study, follow request parsing into routing and response formatting, then compare the stated laws with the socket-handling code.
